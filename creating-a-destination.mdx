Creating a destination is **Step 1 of 10** in the **Package Configuration Wizard** in **Pearl CRM**. This step establishes the core country/region information, descriptive marketing copy, spoken languages, and hero imagery for all tour packages published under this geographical node.

</Note>

## Progress Tracker & Form Sections

The top header displays the interactive **10-step progress bar**, highlighting **Step 1: DESTINATION**. You can exit the wizard at any time using the **CANCEL** button in the banner.

## Form Field Specifications

<AccordionGroup>
  <Accordion title="Step 1 Form Field Specifications" icon="list-check">
    - **Continent** `*` `Dropdown (Required)` — Select the overarching geographic continent from the dropdown menu (e.g., _Europe_, _Asia_, _Africa_).
    - **Country** `*` `Dropdown (Required)` — Select the specific destination country from the dropdown menu.
    - **Currency** `Dropdown` — Select the primary operating billing currency for this region.
    - **Description** `Rich Text` — Marketing summary for the destination (up to 2,000 characters). Supports headings, bolding, italics, underline, strike-through, blockquotes, ordered/unordered lists, links, or inline images.
    - **Languages** `Multi-Select Dropdown` — Select the primary languages spoken in this destination.
    - **Hero Image** `File Upload` — Cover image for the destination page. Recommended size: `1920 x 1080 px` for optimal web display (any image size accepted).
  </Accordion>
</AccordionGroup>

## Step-by-Step Setup Instructions

<Steps>
  <Step title="Configure Basic Information">
    Establish the core location attributes:

    - **Continent** `*` `Dropdown (Required)` — Select the overarching geographic continent from the dropdown menu (e.g., _Europe_, _Asia_, _Africa_).
    - **Country** `*` `Dropdown (Required)` — Select the specific destination country from the dropdown menu.
    - **Currency** `Dropdown` — Select the primary operating billing currency for this region.
  </Step>
  <Step title="Write Destination Overview">
    Use the rich-text editor under **Description** to write a comprehensive marketing summary for the destination (up to 2,000 characters).

    - **Formatting Options**: Apply headings, bolding, italics, underline, strike-through, blockquotes, ordered/unordered lists, links, or inline images.
  </Step>
  <Step title="Select Spoken Languages">
    Under **Languages**, select the primary languages spoken in this destination from the multi-select dropdown field.
  </Step>
  <Step title="Upload Hero Media">
    Under **Hero Image**, click **UPLOAD HERO IMAGE** to attach a cover image for the destination page.

    - **Recommended Size**: `1920 x 1080 px` for optimal web display (any image size accepted).
  </Step>
  <Step title="Proceed to Step 2 (Packages)">
    Click **Save & Continue** (or **Next**) at the bottom of the page to save the destination node and move to **Step 2: Packages**.
  </Step>
</Steps>

---

<Note>
  **Mandatory Fields**: Fields marked with a red asterisk (`*`) are required to validate and save Step 1.
