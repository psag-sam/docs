The **Reports** module in **Pearl CRM** serves as an analytical engine allowing users to build custom report queries on any object, chart business data, organize templates into folders, and pin reports to dashboards.

![Screenshot 2026 09 30 110106](/images/Screenshot-2026-09-30-110106.png "Screenshot 2026 09 30 110106")

## Overview

The Reports workspace provides folder navigation, category management, pre-built templates, and custom report creation tools for real-time reporting across sales, support, and booking operations.

## Directory Sidebar & Folder Navigation

<AccordionGroup>
  <Accordion title="Sidebar Navigation & Folder Categories" icon="folder-open" color="#3B82F6">
    - **All Reports**: Displays the complete ledger of all saved custom reports and system reports accessible to the user.
    - **Created By Me**: Filters the view to show only reports generated by the logged-in account owner.
    - **Shared With Me**: Displays reports created by team members and shared across the organization.
    - **Templates**: Standard pre-built report definitions ready to run or customize.
    - **Folders Section**: Custom directory folders used to group reports logically (e.g., `Report Templates`). Click the **\+ Folder** icon to create new folders.
  </Accordion>

  <Accordion title="Reports Toolbar & Action Controls" icon="sliders" color="#10B981">
    - **Search Bar**: Real-time filter bar to search saved reports by report name or description keywords.
    - **\+ New Report**: Launches the report creation builder wizard to build custom report queries across any CRM object.
  </Accordion>
</AccordionGroup>

## Master Reports Table

The main reports view indexes active report items with the following parameters:

<AccordionGroup>
  <Accordion title="Directory Table Columns" icon="table" color="#3B82F6">
    - **Report Title & Icon** \* Text & Identifier (Required) — Identifies the report type and visual format (e.g., `Bookings by Payment Status (copy)`, `Bookings by Status (copy)`, `Lead Source Performance (copy)`, `Revenue Report`, `Test Sam`).
    - **Description** \* Text (Optional) — Brief summary outlining report scope and calculated parameters (e.g., _Paid, partially paid and pending across live bookings_).
    - **Last Run Date** \* Date (System) — Timestamp indicating the last execution date (e.g., `Run 9/24/2026`, `Never run`).
    - **Row Actions (Three Dots Menu)** \* Contextual Menu (System) — Quick-action dropdown providing options to **Run**, **Edit**, **Duplicate**, **Export**, or **Delete** the report record.
  </Accordion>
</AccordionGroup>
