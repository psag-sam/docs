## Overview

Accounts represent organizational entities within Pearl CRM. The master directory provides dynamic tracking of corporate partnerships, client classification types, geographical locations, annual revenues, and account ownership.

## Master Accounts Table

The central table lists all registered account records with the following parameters:

<AccordionGroup>
  <Accordion title="Organization & Classification Fields" icon="sitemap">
    - **NAME**: Clickable link displaying the legal name of the organization or company account, which opens the **Account Details View**.
    - **ACCOUNT TYPE**: Operational classification of the account (e.g., `Company`, `Partner`).
    - **PARTNER TYPE**: Specific partner role classification (e.g., `Merchant`, `Guide`).
    - **SERVICE TYPE**: Primary fulfillment services provided (e.g., `DMC`, `Activity`, `Accommodation`).
  </Accordion>

  <Accordion title="Location & Industry Context" icon="earth-americas">
    - **COUNTRY**: Primary operating country location.
    - **INDUSTRY**: Market vertical or industry classification (e.g., `Travel`, `Construction`, `Education`).
    - **ACCOUNT STATUS**: Active operational state (`Active` or `Draft`).
  </Accordion>

  <Accordion title="Financial & Ownership Details" icon="wallet">
    - **ANNUAL REVENUE**: Commercial revenue scope registered for the organization.
    - **CURRENCY**: Primary transaction currency linked to the account (e.g., `INR`, `AUD`).
    - **OWNER**: Clickable link displaying the assigned internal sales agent or account manager, which opens the corresponding user's **User Profile** page.
    - **MODIFIED DATE**: Timestamp indicating the most recent record modification.
  </Accordion>
</AccordionGroup>

## Directory Toolbar & Filtering Controls

Manage directory views and perform record actions using the top toolbar controls:

<CardGroup cols={2}>
  <Card title="Dynamic Real-Time Search Bar" icon="magnifying-glass">
    Type directly into the `Search...` field to dynamically filter table rows in real-time across company names, owners, countries, or industries.
  </Card>

  <Card title="Filtered CSV Export" icon="file-csv">
    Adjust entry limits per page or click **CSV** to download a spreadsheet containing only the currently filtered table records.
  </Card>

  <Card title="Advanced Multi-Condition Filter" icon="filter">
    Click the **Funnel** icon to launch the **Filter Accounts** modal. Construct custom multi-condition queries using `All conditions (AND)` or `Any condition (OR)` logic across 24 configurable record fields.
  </Card>

  <Card title="Saved Filter Presets" icon="bookmark">
    Click the **Bookmark** icon to access the **Saved Filters** dropdown menu. Easily apply saved presets, edit conditions, delete filters, or select **Clear Filter** to restore default settings.
  </Card>

  <Card title="+ Add Account Action" icon="plus">
    Click **\+ Add Account** to initiate the account creation workflow.
  </Card>
</CardGroup>
