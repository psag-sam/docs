# Introduction

Welcome to the **Pearl CRM** user documentation. Pearl CRM is an all-in-one agency workspace designed to streamline lead management, travel package configuration, booking execution, and customer communication.

## Workspace Interface Overview

### Top Navigation Controls

- **Font Controls**: Adjust text font size across the workspace.
- **Reset View**: Reset page state and active filters to default settings.
- **Feedback**: Open internal feedback and quick messaging panel.
- **Notifications**: View system notifications, updates, and pending action items.
- **Settings**: Access workspace configuration and administration settings.
- **User Profile**: View account settings, profile information, and sign-out options.

---

## Workspace Dashboards

Dashboards in Pearl CRM provide dynamic, real-time summaries tailored to user roles and operational needs.

### Managing & Switching Dashboards

- **Default Views**: Each user role is assigned a default home dashboard view.
- **Change Button**: Click **Change** to navigate to the **Dashboards Management** hub.
- **Customization & Selection**: Browse built-in or custom dashboards, create new dashboard layouts (`+ New dashboard`), and select or pin any dashboard as your default home view.

---

### Dashboard Component Mechanics

Dashboards consist of modular widgets that display real-time data according to your permissions and filters:

- **Metric Summary Cards**: Highlight key single-value KPIs (such as outstanding balances or active pipeline counts).
- **Report Data Tables**: Display scrollable list views for active records, upcoming departures, or pending payments. Tables feature field columns, status indicators, and aggregated summary total rows.
- **Visual Charts**: Provide graphical representations (such as bar charts) summarizing booking values or operational statuses.
- **Drill-Down Access (**`↗`**)**: Clicking the pop-out icon on supported widgets opens the full underlying report view for detailed filtering and data extraction.

---

### Integrated Softphone Widget

Located persistently in the bottom-right corner of the workspace:

- **Phone Dialer**: Expands an embedded keypad with direct number input and call initiation.
- **Agent Availability Status**: Allows setting phone status to _Available_, _Busy_, _On break_, _Lunch_, _In a meeting_, _Training_, or _Offline_.
