The **Templates** tab (`/Settings/Company-Settings`) in **Pearl CRM** allows administrators to select, preview, and customize standardized layout templates for generated transactional documents and customer communications.

![Screenshot 2026 10 01 095957](/images/Screenshot-2026-10-01-095957.png "Screenshot 2026 10 01 095957")

## Overview

Template settings govern the visual formatting and layout structure of customer-facing billing invoices, official quotes, orders, and automated message dispatches across email and WhatsApp channels.

<CardGroup cols="{2}">
  <Card title="Transactional Documents" color="#3B82F6" icon="file-invoice">
    Standardize visual layouts for billing invoices, price estimates, sales quotes, and travel order receipts.
  </Card>

  <Card title="Multi-Channel Messages" color="#10B981" icon="comments">
    Configure automated output templates for email correspondence, specialized travel itineraries, and WhatsApp messaging.
  </Card>
</CardGroup>

## Template Categories

Administrators can configure templates organized under two main operational categories:

<AccordionGroup>
  <Accordion title="1. Document Templates" icon="file-lines" color="#3B82F6">
    - **Invoice**: Default template design for billing and transaction records (e.g., _Standard India Template_, _Global-US/UK/Europe Template_, or _Custom Template_).
    - **Quote**: Standardized layout for client price estimates and sales proposals.
    - **Order**: Structural formatting for travel order summaries and booking receipts.
  </Accordion>

  <Accordion title="2. Communication Templates" icon="message" color="#10B981">
    - **Email**: Standard system templates for outbound email correspondence.
    - **Travel Order Email**: Specialized layout for sending travel itineraries and booking confirmations via email.
    - **WhatsApp**: Message formatting templates for automated or manual WhatsApp notifications.
  </Accordion>
</AccordionGroup>

## Managing Templates

<Steps>
  <Step title="Select Category" icon="list-check">
    Select a category from the left navigation menu (e.g., **Invoice**).
  </Step>
  <Step title="Preview Layouts" icon="eye">
    Hover or click on any available layout option to **Preview Template** details.
  </Step>
  <Step title="Activate Default Template" icon="circle-check">
    Select the preferred active layout badge (e.g., **Global-US/UK/Europe Template**) to set it as the default output format for generated documents.
  </Step>
</Steps>
