## Overview

While **Accounts** represent business organizations or travel groups, **Contacts** represent individual people (such as primary account holders, travelers, travel agents, or vendor representatives). The master directory tracks personal contact information, associated parent accounts, primary contact designations, and record statuses.

## Directory Toolbar Actions

Filter, export, and manage contacts efficiently using the main action bar controls:

<AccordionGroup>
  <Accordion title="1. Filtering & Saved Views" icon="filter">
    - **Filter Icon**: Click the filter button to toggle advanced field-level filters.
    - **Bookmark Icon**: Access saved filter views to quickly isolate primary liaisons, draft records, or account-specific contacts.
  </Accordion>

  <Accordion title="2. Table Search & Pagination Settings" icon="sliders">
    - **Inline Search Bar**: Filter contacts dynamically by name, email address, or account title.
    - **Entries Per Page**: Adjust page record display density (e.g., `10 entries per page`) using the dropdown selector.
  </Accordion>

  <Accordion title="3. Data Export & Record Creation" icon="file-export">
    - **CSV Export**: Click the **CSV** icon to export the filtered contact list to a standard `.csv` spreadsheet.
    - **Add Contact Button**: Click **\+ Add Contact** to launch the creation modal directly on the screen.
  </Accordion>
</AccordionGroup>

## Master Contacts Directory Table

The central table displays all registered person records with rich status indicators and contextual action menus:

<Tabs>
  <Tab title="Directory Data Fields" icon="table-list">
    | Column Header | Field Type / Format | Interactive Behavior & Description |
    | :-- | :-- | :-- |
    | **CONTACT NAME** | Hyperlink | Full name of the contact (e.g., `Alexander Wright`, `Sonam Tripathi`). Clicking navigates directly to the **Contact Details View** page (`/contacts/{id}`). |
    | **ACCOUNT** | Hyperlink | Parent organization title (e.g., `Alexander Wright Travel`, `PearlCRM`). Clicking navigates directly to the parent **Account Details View** page (`/accounts/{id}`). |
    | **EMAIL** | Text | Primary email address (e.g., `alexander.wright@example.com`). |
    | **PHONE** | Text / Digits | Direct telephone or direct office number. |
    | **PRIMARY CONTACT** | Status Badge | Displays a blue `● Primary` badge if designated as the main liaison for the account; otherwise displays a dash (`-`). |
    | **STATUS** | Status Badge | Operational record status indicator (`● Draft` or `● Active`). |
    | **ACTION** | Kebab Menu (`⋮`) | Opens a pop-up action menu for the specific contact row. |
  </Tab>
  <Tab title="Row Actions Menu" icon="ellipsis-vertical">
    ### Row Kebab Options (`⋮`)

    Clicking the action menu icon on any table row exposes direct quick actions:

    <CardGroup cols={2}>
      <Card title="View Record" icon="eye">
        Navigates directly to the detailed profile screen for the selected contact.
      </Card>

      <Card title="Delete Record" icon="trash-can">
        Removes the contact record permanently from the Pearl CRM database.
      </Card>
    </CardGroup>
  </Tab>
</Tabs>
