## Overview

Package FAQs address routine customer questions regarding package inclusions, passport/visa requirements, payment policies, cancellation guidelines, and transit details.

<CardGroup cols="{2}">
  <Card title="Buyer Conversion" color="#3B82F6" icon="circle-question">
    Provide proactive responses to common queries directly on booking portals to reduce support friction.
  </Card>

  <Card title="Visibility Control" color="#10B981" icon="eye">
    Manage internal draft states and control public display using the Published toggle on each FAQ entry.
  </Card>
</CardGroup>

## FAQ Configuration Parameters

Each FAQ entry consists of the following parameters:

<AccordionGroup>
  <Accordion title="FAQ Details & Settings" icon="list-check" color="#3B82F6">
    - **Question** \* Text (Required) — Enter the customer query (e.g., `What is included in the Copenhagen Hotel & Transfer Package?`).
    - **Answer** \* Text (Required) — Enter the detailed response (e.g., _The package includes 4-star city center accommodation with daily breakfast, private arrival and departure airport transfers, and guided walking tours as outlined in the itinerary_).
    - **Published** \* Checkbox (Optional) — Check this box to make the FAQ publicly visible on frontend trip listings. Uncheck it to keep the entry saved internally as a draft.

    To add additional query cards for this package, click **\+ Add FAQs** at the bottom of the section.
  </Accordion>
</AccordionGroup>

## Form Navigation Actions

At the bottom of the form screen, manage wizard progression:

<CardGroup cols="{2}">
  <Card title="Navigation Controls" color="#3B82F6" icon="arrow-left">
    - **Card Controls**: Use the icons in the upper right corner of each card block to duplicate or remove an FAQ entry.
    - **BACK**: Return to Step 8 (Add-ons) to review optional upgrades.
    - **SAVE DRAFT**: Save current FAQ entries without advancing the wizard.
  </Card>

  <Card title="Next Phase" color="#10B981" icon="arrow-right">
    - **Continue →**: Save FAQ configurations and proceed directly to **Step 10: Review**.
  </Card>
</CardGroup>
