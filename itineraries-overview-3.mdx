The **Itinerary Builder** is **Step 7 of 10** in the **Package Configuration Wizard** in **Pearl CRM**. This step structures the overarching trip program, master package inclusions and exclusions, and the day-by-day itinerary schedule.

![Image](/images/image-44.png "Image")

<Note>
  **Currency Inherited**: All pricing figures referenced within itinerary line items automatically use the operating currency set during Step 3 (Pricing & Billing).
</Note>

## Overview

The Itinerary Builder converts logistics and destination assets into a coherent traveler agenda. Day blocks are automatically generated based on the total trip duration defined during Step 2 (Trip Packages).

<CardGroup cols="{2}">
  <Card title="Program Identity" color="#3B82F6" icon="compass">
    Define master package details, high-level schedules, and overarching travel boundaries.
  </Card>

  <Card title="Daily Agendas" color="#10B981" icon="calendar">
    Configure individual day blocks with chronological activities, logistics, and site entries.
  </Card>
</CardGroup>

## Form Configuration & Schedule Setup

<AccordionGroup>
  <Accordion title="Overall Itinerary Configuration" icon="sliders" color="#3B82F6">
    Define the high-level program identity and overall service boundaries:

    - **Itinerary Title** \* Text (Required) — Enter the primary title for the package schedule (e.g., `7-Day Copenhagen & Danish Cultural Experience`).
    - **Inclusion** \* Text (Optional) — Use the rich-text editor to list all baseline items included in the package price (e.g., _4-star hotel accommodations with daily breakfast, private arrival and departure transfers, entrance fees to Tivoli Gardens and Rosenborg Castle, and guided walking tours_).
    - **Exclusion** \* Text (Optional) — Use the rich-text editor to list non-included expenses (e.g., _International airfare, personal travel insurance, lunches and dinners unless specified, and personal expenses_).
  </Accordion>

  <Accordion title="Daily Schedule Structure" icon="calendar-days" color="#8B5CF6">
    The **Daily Schedule** section displays individual day blocks corresponding to the package duration (e.g., _Daily Schedule (7 days)_).

    <Steps>
      <Step title="Configuring Day Titles & Reusing Schedules">
        - **Day Title** \* Text (Required) — Enter a descriptive headline for each specific day (e.g., `Day 1: Arrival in Copenhagen & Welcome Dinner`).
        - **Copy from day** \* Button (Optional) — For subsequent days (Day 2 onwards), click **Copy from day** to replicate the structure or line items from an existing day block.
      </Step>
      <Step title="Adding Day-Wise Line Items">
        Click **\+ Add Line Item** within any day block to attach individual activity, meal, or transit details:

        - **Item Title** \* Text (Required) — Enter the activity or event name.
        - **Trip Logistics** \* Dropdown (Required) — Select the associated service component configured in Step 4.
        - **Location** \* Text (Optional) — Enter the physical venue, city, or geographical site.
        - **Sequence** \* Number (Required) — Numerical value determining the order of the activity on that day.
        - **Notes** \* Text (Optional) — Rich-text editor for detailed descriptions, meeting instructions, or itinerary notes.
      </Step>
    </Steps>
  </Accordion>
</AccordionGroup>

## Master Directory Management

Once configured in the Package Configuration Wizard, all day-by-day traveler agendas sync to the central **Itineraries** module in **Pearl CRM**.

![Image](/images/image-16.png "Image")

<AccordionGroup>
  <Accordion title="Directory Table Columns" icon="table" color="#EC4899">
    - **ITINERARY**: The master title of the itinerary program (e.g., _7-Day Copenhagen & Danish Cultural Experience_).
    - **TRIP**: Displays the associated parent trip or destination grouping.
    - **DAYS**: Total number of scheduled itinerary days generated from the package duration.
    - **ATTRACTIONS**: Key sights and venue experiences attached across all daily line items.
    - **STATUS**: Operational visibility state (_active_ or _draft_).
    - **CREATED**: Timestamp indicating when the itinerary record was generated.
    - **ACTIONS**: Contextual kebab menu (`:`) for editing or managing the itinerary record.
  </Accordion>

  <Accordion title="Directory Toolbar & Actions" icon="wrench" color="#F59E0B">
    - **Search Bar**: Filter the itinerary list dynamically by title, destination, or status.
    - **Filter & Bookmark Controls**: Apply saved custom views or filter itineraries by specific parameters.
    - **CSV Export**: Download the active list of itineraries as a spreadsheet.
    - **\+ ADD ITINERARY**: Launches a modal window allowing operators to select a target package from a dropdown menu and jump directly to Step 7 in the Package Configuration Wizard.
  </Accordion>
</AccordionGroup>
