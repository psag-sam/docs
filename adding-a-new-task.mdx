The **Create New Task** modal in **Pearl CRM** allows agents and team members to schedule activities, follow-up calls, and deadlines linked to core CRM records.

![Screenshot 2026 09 30 105105](/images/Screenshot-2026-09-30-105105.png "Screenshot 2026 09 30 105105")

<Note>
  **Validation Rules**: Fields marked with a red asterisk (`*`) are required to validate and save the scheduled task on the calendar.
</Note>

## Overview

Tasks ensure scheduled touchpoints are tracked across customer accounts, leads, deals, cases, or travel orders. Scheduled tasks automatically appear on the master Tasks calendar view.

  <Card title="Touchpoint Tracking" color="#3B82F6" icon="calendar-check">

## Step-by-Step Task Creation

<Steps>
  <Step title="Open the Creation Modal" icon="square-plus">
    From the **Tasks** calendar view, click **Create Task** to open the task creation dialog.
  </Step>
  <Step title="Enter Task Details" icon="pen-to-square">
    Configure core activity fields:

    - **Task Type** \* Dropdown (Optional) — Select the type of activity (e.g., `Task`).
    - **Title** \* Text (Required) — Enter a clear, action-oriented title for the task (e.g., `Follow up with Ravensburg Services on travel itinerary confirmation`).
    - **Description** \* Textarea (Optional) — Add relevant background notes, call instructions, or specific items to discuss.
    - **Due Date** \* Date & Time (Optional) — Select the date and time for the activity (e.g., `10/02/2026 10:50 AM`).
    - **Owner** \* Dropdown (Optional) — Designate the user responsible for completing the task (e.g., `sarthak.naulakha@psag`).
  </Step>
  <Step title="Relate Task to CRM Entities" icon="link">
    Associate the activity with relevant system records:

    - **Related To** \* Dropdown (Optional) — Select the object type you want to link the task to (`Account`, `Case`, `Deal`, `Travel Order`).
    - **Search Field** \* Dropdown (Optional) — Search and select the specific record name or entity (e.g., `Ravensburg Services`).
  </Step>
  <Step title="Save Task" icon="floppy-disk">
    Click **Create Task** to schedule the entry on your calendar, or click **Cancel** to discard changes.
  </Step>
</Steps>
