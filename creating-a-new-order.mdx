title: "Creating a New Order"
---

The manual booking wizard lets you configure a new travel order through a guided step-by-step process.

## Step 1: Select Trip & Departure Date

Use the controls to locate and select the desired travel package and travel dates:

- **Search & Filter:** Filter available packages by destination name or departure date ranges.
- **Package Cards:** Click any package card to select it. Cards display key details including package image, title, duration, base price per person, and customer rating.

## Order Summary Sidebar

The dynamic panel on the right recalculates totals in real-time. It tracks package selection, traveler counts, base prices, applied discounts, VAT tax breakdowns, and final calculated amounts.
