The **API Integrations** workspace in **Pearl CRM** (`/Settings/Integrations`) enables system administrators to configure third-party API keys required for location-based mapping, AI capabilities, and tax compliance services.

![Screenshot 2026 10 01 121425](/images/Screenshot-2026-10-01-121425.png "Screenshot 2026 10 01 121425")

## Overview

API Integrations serve as external service connectors for Pearl CRM. By storing secure API credentials centrally, Pearl CRM connects to external provider engines to perform automated tasks—such as address geolocation, AI text generation, and dynamic GST lookup—without custom backend code.

## Workspace Layout & Controls

The API Integrations tab is organized into service-specific configuration cards:

<AccordionGroup>
  <Accordion title="Security & Workspace Controls" icon="shield-check" color="#3B82F6">
    - **Tab Bar Navigation**: Switch between `Webhooks`, `API Integrations`, and `Social`.
    - **Input Key Masking**: All API key fields automatically mask secret characters (`••••••••`) to prevent visual disclosure.
    - **Visibility Toggle (👁)**: Allows authorized administrators to reveal secret keys in plain text for audit or updates.
    - **Save Settings Button**: Encrypts and saves updated keys globally across system features.
  </Accordion>
</AccordionGroup>
