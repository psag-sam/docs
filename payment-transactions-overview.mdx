## Overview

While Payment Templates define commercial billing terms upfront, **Payment Transactions** record live payment events—including deposits, final balances, full payments, and scheduled installments. This module gives finance and operations teams an audit trail to monitor payment collections, review method distributions, and track pending balances across all customer orders.

## Data Table Structure

The Payment Transactions table organizes financial records across standard operational parameters:

<AccordionGroup>
  <Accordion title="Directory Table Columns" icon="table" color="#3B82F6">
    - **NAME** \* Identifier (System) — System-generated transaction identifier code (e.g., _PTX-173_, _PTX-172_, _PTX-171_).
    - **ORDER** \* Text (Optional) — Unique reference code linking directly to the corresponding travel order (e.g., _TO-2026-00176_).
    - **INVOICE** \* Text (Optional) — Associated invoice reference code (e.g., _INV-0072_, _INV-0053_).
    - **PAYMENT DATE** \* Date (System) — Timestamp indicating when the payment was processed or recorded.
    - **AMOUNT** \* Currency & Number (Required) — Monetary value recorded for the transaction.
    - **METHOD** \* Dropdown (Required) — Payment channel or instrument used (e.g., _Card_).
    - **MODE** \* Dropdown (Required) — Specific payment milestone classification (_Full Payment_, _Deposit_, _Final Balance_).
    - **STATUS** \* Status (System) — Current financial processing state indicated by a color-coded badge (_Payment Pending_ or _Paid_).
    - **ACTION** \* Contextual Menu (System) — Context menu control to view details, update status, or manage the transaction record.
  </Accordion>
</AccordionGroup>
