<Note>
  **Overview**: Defining pricing parameters ensures that bookable packages have standardized financial bases and supported billing schedules. The selected currency here governs all subsequent pricing calculations across trip logistics, departure surcharges, and optional add-ons.
</Note>

## Form Configuration Sections

<AccordionGroup>
  <Accordion title="1. Pricing & Billing Parameters" icon="calculator">
    Set the baseline cost and operating currency for the tour:

    - **Base Price** `*` `Numeric (Required)` — Enter the starting price per traveler for the package (e.g., `1499`).
    - **Trip Currency** `*` `Dropdown (Required)` — Select the governing transaction currency from the dropdown menu (e.g., _EUR - Euro_, _DKK - Danish Krone_).
  </Accordion>

  <Accordion title="2. Payment Templates Selection" icon="credit-card">
    Select one or more pre-configured billing structures to determine how clients can pay for this package during checkout:

    - Check the selection box next to any active template (e.g., _10 % deposit_, _Pay your way!_, _Premium Template_).
    - Edit an existing template structure inline by clicking the **Pencil Icon** on the right side of any template card.
  </Accordion>
</AccordionGroup>

## Adding a Payment Template On the Go

If the required commercial structure is not listed, click **\+ NEW TEMPLATE** in the section header to open the inline creation modal:

<Steps>
  <Step title="Open Inline Modal">
    Click the **\+ NEW TEMPLATE** button in the **Payment Templates** section header.
  </Step>
  <Step title="Configure Template Metadata">
    Complete mandatory modal setup fields:

    - **Template Name** `*` `Text Input (Required)` — Enter a descriptive identifier (e.g., _Standard Split_, _20% Early Deposit_).
    - **Payment Type** `*` `Dropdown (Required)` — Select the payment breakdown structure (_Deposit + Final Balance_, _Deposit + Installments_, or _Full Payment_).
  </Step>
  <Step title="Set Status & Save">
    Set **Status** (_Active_, _Draft_, or _Inactive_) and click **SAVE TEMPLATE** to save the rule and instantly select it for this package.
  </Step>
</Steps>
