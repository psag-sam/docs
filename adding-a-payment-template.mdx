<Note>
  **Overview**: Creating Payment Templates allows your organization to standardize billing expectations across all travel offerings. Once established, these templates can be attached to packages during Step 3 (Pricing) of the Package Configuration Wizard or selected when sending payment links during order checkout.
</Note>

---

## Step-by-Step Template Setup

<Steps>
  <Step title="Open Template Modal">
    In the **Payment Templates** dashboard header, click the **\+ CREATE TEMPLATE** button.
  </Step>
  <Step title="Configure Basic Information">
    Complete mandatory modal setup fields:

    - **Template Name** `*` `Text Input (Required)` — Enter a clear, descriptive name for internal identification (e.g., _Standard Split_, _10% Deposit_, _Full Payment Plan_).
    - **Payment Type** `*` `Category (Required)` — Select the governing billing classification from the dropdown (_Deposit + Final Balance_, _Deposit + Installments_, or _Full Payment_).
  </Step>
  <Step title="Set System Status">
    Set the operational state of the template using the **Status** dropdown:

    - **Draft**: Saves the template structure internally for review without making it active.
    - **Active**: Publishes the template for immediate selection in packages and orders.
    - **Inactive**: Archives the template to prevent further assignment.
  </Step>
  <Step title="Save Template">
    Click **SAVE TEMPLATE** to create the schedule structure and add it to your global template list.
  </Step>
</Steps>

---

<Note>
  **Required Fields**: Fields marked with a red asterisk (`*`) are mandatory and must be completed before saving the payment template.
</Note>
