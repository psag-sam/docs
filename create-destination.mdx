## Basic Information

Configure the foundational regional parameters for the destination:

- **Continent \*:** Select the geographical region.
- **Country \*:** Choose the destination country (it will only display the countries of the selected continent).
- **Currency:** Select the primary operating currency.

## Destination Overview & Description

Use the rich-text editor to craft customer-facing copy for the destination:

- **Description Editor:** Write an engaging summary detailing local landmarks, cultural identity, and appeal. Supports standard formatting options including bolding, lists, and hyperlinks (up to 2,000 characters).

## Languages, Media & Key Highlights

Upload media assets and configure regional highlights:

<Steps>
  <Step title="Languages Selection" icon="language">
    Choose all applicable regional or official languages from the **Languages** dropdown (e.g., **English**, **Hindi**).
  </Step>
  <Step title="Hero Image Upload" icon="image">
    Upload the main cover photo for the destination page.

    - **REPLACE PHOTO / REMOVE:** Options to manage or update the cover image.
    - **Recommended Dimensions:** $$1920 \times 1080\text{ px}$$ for widescreen display.
  </Step>
  <Step title="Key Highlights Gallery" icon="star">
    Attach feature landmarks and experiences using **\+ ADD HIGHLIGHT**.

    - **Gardens by the Bay & Supertree Grove** (`18 Marina Gardens Dr, Singapore 018953`)
    - **Marina Bay Sands SkyPark** (`10 Bayfront Ave, Singapore 018956`)
    - **Recommended Image Size:** $$1200 \times 627\text{ px}$$.
  </Step>
</Steps>
