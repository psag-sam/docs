<Note>
  **Overview**: Destinations establish the geographical anchors for all tour packages in your system. As the top-level parent node, every trip package must belong to a registered destination. Clicking **\+ CREATE DESTINATION** launches Step 1 of the overarching 10-step package creation wizard.
</Note>

## Data Table Structure

The Travel Destinations table categorizes geographic regions across standard operational fields:

<AccordionGroup>
  <Accordion title="Travel Destinations Table Attributes" icon="table">
    - **COUNTRY NAME** `String` — Name of the destination country (e.g., _South Africa_, _Singapore_, _India_, _Italy_, _Georgia_, _Sri Lanka_, _Bangladesh_, _Nepal_, _Armenia_).
    - **CONTINENT** `Category` — Geographic continent classification (e.g., _Europe_, _Africa_, _Asia_).
    - **PACKAGES** `Numeric` — Count of active and draft trip packages linked to the destination.
    - **STATUS** `Status Badge` — Operational state indicated by a badge (_active_ or _draft_).
    - **CREATED** `Date Stamp` — Date stamp indicating when the destination entry was generated.
    - **MODIFIED** `Date Stamp` — Date stamp of the most recent configuration update.
    - **ACTIONS** `Row Menu` — Row menu button to edit, update, or inspect the destination.
  </Accordion>
</AccordionGroup>

## The 10-Step Package Configuration Wizard Walkthrough

When you click **\+ CREATE DESTINATION**, Pearl CRM guides you through a sequential 10-step wizard to build and publish a fully configured travel package:

<Steps>
  <Step title="1. Destination">
    Define core geographic attributes, description, spoken languages, and hero media for the country/region.
  </Step>
  <Step title="2. Packages">
    Create the trip package shell, setting its title, code, overview, inclusions/exclusions, and duration.
  </Step>
  <Step title="3. Pricing">
    Set up base package costs, currency rates, and attach payment schedule templates or deposit structures.
  </Step>
  <Step title="4. Trip Logistics">
    Select or attach master service items—such as room types, transfers, meals, and activities—to the package.
  </Step>
  <Step title="5. Departures">
    Configure specific departure date schedules, available seat/inventory capacity, and attach High Season Surcharges (HSS).
  </Step>
  <Step title="6. Allocations">
    Assign logistics services to partner vendor accounts (Merchant Accounts) for operational fulfillment.
  </Step>
  <Step title="7. Itineraries">
    Build the day-by-day traveler journey, adding day schedule blocks and attaching day-wise line items.
  </Step>
  <Step title="8. Add-ons">
    Configure optional upgrades and experiences that clients can purchase across the entire trip or on specific days.
  </Step>
</Steps>
